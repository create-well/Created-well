## How to Continue Development

### Adding a new feature
1. Edit the relevant view component in `src/views/`
2. Add API functions to `src/api.ts` if needed
3. Update `TopNav.tsx` if adding new nav items
4. Run `npm run build` locally to verify
5. Deploy with `npx vercel@latest --prod --yes`

### Modifying the Notion sync
1. Edit the relevant Edge Function in `supabase/functions/sync-{to,from}-notion/`
2. Redeploy via Supabase MCP `deploy_edge_function`
3. Test by clicking the 🔄 Sync button in the dashboard

### Adding a new real-time table
1. Create table in Supabase with RLS policies
2. Generate types: `supabase gen types typescript`
3. Create a hook in `src/hooks/use{Table}Realtime.ts`
4. Use the hook in the relevant view

### Post-Figma-Make Sync Recovery
If Figma Make sync breaks the build:
1. `git diff --name-only` — see what changed
2. Restore `.gitignore` if missing
3. Recreate `config.ts` from `info.tsx` values if missing
4. Fix imports in `api.ts` and `App.tsx`
5. `npm run build` to verify
